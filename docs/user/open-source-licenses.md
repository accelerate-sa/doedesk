# Open source licenses

T3 Code includes third-party software and adapted assets. To read their license and attribution
notices:

- On web and desktop, open **Settings → About**, find **Open source licenses** under **Legal**,
  and select **View licenses**.
- On mobile, open **Settings → About T3 Code → Open source licenses**.

The page lists the version when available, license identifier, and the parts of T3 Code that include
or use the item. This also covers optional device tools that T3 Code installs on demand instead of
bundling. Select a row to read the complete notice text. Use the search field to find a package,
version, license, or app component.

## DoeDesk's own license

DoeDesk is free software under the GNU Affero General Public License, version 3 or later. The code
it takes from T3 Code is under the MIT license. Both texts are in the same list, under **DoeDesk**
and **T3 Code**.

To get the source of the version you are using, open **Settings → About** and select **View
source** beside **Source code**. On mobile, open **Settings → About → Source code**.
