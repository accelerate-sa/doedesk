# Bundled reading fonts

- `DoeDeskSerif-*.ttf`: Redaction (MCKL) with its digits replaced by Newsreader's (Production
  Type), because Redaction's "1" reads as a lowercase "l" and native text cannot take digits
  from a second font. A modified version of both, so it carries its own name. Generated by
  `scripts/build-brand-fonts.py`; do not edit by hand. Licences: `LICENSE-Redaction.txt`,
  `LICENSE-Newsreader.txt`.
- `NotoNaskhArabic-*.ttf`: static regular and bold instances of Noto Naskh Arabic.
  Licence: `LICENSE-NotoNaskhArabic.txt`.
